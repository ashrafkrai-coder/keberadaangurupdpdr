Panduan Ringkas
  1. Pasang app: Android Chrome → menu ⋮ → Install app. iPhone Safari → Kongsi → Add to Home Screen.
  2. Tekan Mula Kongsi Lokasi dan pilih Allow / Benarkan semasa menggunakan app.
  3. Biarkan app terbuka semasa waktu bertugas. Skrin akan dikekalkan menyala secara automatik.
  4. Kongsi lokasi berhenti sendiri apabila tamat waktu bertugas.
  5. Jika status menjadi Offline, buka semula app dan tekan Mula.
