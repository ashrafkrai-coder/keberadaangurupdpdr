Akaun Tidak Aktif

Daftarkan lokasi rumah anda

Lakukan sekali sahaja semasa berada di rumah. Check-in akan disahkan berdasarkan lokasi ini. Anda tidak boleh mengubahnya sendiri selepas ini.

Penjejakan tertakluk kepada had pelayar: app mesti kekal terbuka dan skrin menyala. Jika skrin dikunci, tekan Check-in secara manual.

Rekod Terkini

    Belum ada rekod check-in.

    Panduan Ringkas
    1. Pasang app: Android Chrome → menu ⋮ → Install app. iPhone Safari → Kongsi → Add to Home Screen.
    2. Daftar lokasi rumah sekali semasa berada di rumah.
    3. Setiap sesi, tekan Check-in pada atau sebelum waktu mula. Benarkan akses lokasi apabila diminta.
    4. Hidupkan GPS dan lakukan check-in di dalam atau berhampiran rumah.
    5. Lokasi hanya disimpan pada saat check-in. Jika Check-in automatik dihidupkan, GPS digunakan hanya semasa app terbuka sehingga semua sesi hari ini selesai, dan lokasi semasa penjejakan tidak disimpan.
